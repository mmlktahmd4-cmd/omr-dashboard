لوحة إدارة Connect

كيف تشغّل النظام

  1. وصّل كيبل المودم/الإنترنت إلى محولة USB (eth1 أو eth2).
  2. من تبويب الوصلات اختر DHCP واحفظ الوصلة.
  3. من تبويب السيرفر تأكد من IP السيرفر والتوكن ثم احفظ.
  4. ارجع للحالة حتى يصير السيرفر والنفق أخضر.

ربط سيرفر OpenMPTCProuter (VPS)

أدخل IP + اسم المستخدم + كلمة مرور السيرفر (مفتاح الإدارة من نهاية تثبيت VPS). الربط يتم عبر منفذ الإدارة 65500 فقط — ليس SSH وليس المنفذ 22.
المنافذ الصحيحةإدارة API: 65500 · SSH للسيرفر: 65222 · لا تستخدم المنفذ 22 أبداً لربط المفاتيح.
عادةً: openmptcprouter
هي «OpenMPTCProuter Server key» من مخرجات التثبيت — ليست كلمة مرور SSH.
ثابت على 65500 — جلب المفاتيح لا يستخدم 22 ولا 65222.
